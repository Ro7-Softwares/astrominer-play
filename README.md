## Como esta página se mantém atualizada
Cada build do jogo (no repositório original) publica aqui, de uma vez: o jogo, o APK, o guia em PDF, os créditos e a lista de pendências. Este `README` é copiado do repositório original e **não muda** a cada versão; só os arquivos para onde ele aponta.
